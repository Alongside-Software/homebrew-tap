# Alongside Homebrew tap

Homebrew only guesses at GitHub, so this tap has to be added by URL once:

```sh
brew tap alongside-oss/tap https://gitlab.com/alongside-oss/homebrew-tap.git
```

After that it behaves like any other tap.

## Formulae

- **[siri-say](https://gitlab.com/alongside-oss/siri-say)** — `say`, in a Siri voice.

  ```sh
  brew install alongside-oss/tap/siri-say
  ```
